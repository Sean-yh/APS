> 版本：v1.0
> 更新：2026-01-26
> 目标读者：开发团队

---

## 一、产品定位

**一句话**：基于对话+画布的AI排产助手，帮塑料容器工厂快速响应插单、故障、紧急交期等变化。

**核心价值**：
- 传统ERP是"静态地图"，我们是"实时导航"
- 把老师傅的排产经验算法化，响应速度从"半天"到"秒级"
- 多方案对比，让计划员有选择权而非被动接受

**业务背景**：
- 两阶段生产：成型（3台旋转机）→ 贴标（6台贴标机）
- 3条独立产线（L1/L2/L3），共9台设备
- 换色12小时、换模72小时（仅L1）
- ERP数据滞后1-1.5天

---

## 二、核心流程总览

| Flow | 场景 | 触发方式 | 说明 |
|------|------|---------|------|
| Flow 1 | 首次排产 | "更新排产" | 确认成型机状态后生成排程 |
| Flow 2 | 查询订单/货柜 | "查询xxx" / "xxx会延期吗" | 查看订单、货柜、客户的交期状态 |
| Flow 3 | 任务上下文操作 | 点击甘特图任务 + 输入 | 选中任务后自由输入操作 |
| Flow 4 | 紧急插单/优先级锁定 | "xxx必须在xx前完成" | 客户催货、老板指示优先 |
| Flow 5 | 机器故障/停机 | "ROTARY-1 明天要维修" | 设备临时停机 |
| Flow 6 | 节假日/全厂停产 | "春节1/28放假" | 全厂停产安排 |
| Flow 7 | 方案对比与应用 | "对比不同方案" | 多方案KPI对比后选择 |
| Flow 8 | 导出到ERP | "发到ERP" | 确认并同步生产计划 |
| Flow 9 | 查看操作历史 | "之前做过什么修改" | 回顾排产调整记录 |
| Flow 10 | 做库存/Buffer Stock | "这个多做点库存" / "加5000件库存" | 利用换模间隙多做备货 |

### Flow 3: 任务上下文操作（选中+自由输入）

**触发**：用户在Canvas点击任意任务

**核心理念**：选中即上下文，用户自由输入想做的操作。

```
用户在Canvas点击某个任务
    │
    ▼
任务高亮（蓝色边框），输入框上方显示上下文卡片：

┌─────────────────────────────────────────┐
│ 📍 已选中任务                     [✕]   │
│                                         │
│ 机器：ROTARY-1                          │
│ SKU：S18G9C                             │
│ 订单：#1218288                          │
│ 时间：1/26 08:00 - 1/27 16:00           │
│ 数量：50,000 件                         │
│ 交期：1/30                              │
└─────────────────────────────────────────┘

[针对 S18G9C 任务输入操作...        ] [发送]
    │
    ▼
用户可直接输入任何请求：
    │
    ├─→ "这个订单必须1/28完成"
    │       ↓
    │   AI生成新方案，显示影响对比
    │   用户确认 → Canvas显示新的重排方案
    │
    ├─→ "这个能提前吗"
    │       ↓
    │   AI分析最早可完成时间
    │   回复："最早可在1/27 20:00完成，需要..."
    │
    ├─→ "把这个订单优先级调到最高"
    │       ↓
    │   AI锁定优先级，重新排产
    │   显示对其他订单的影响
    │
    └─→ "取消这个任务"（ESC 或点击 ✕）
            ↓
        取消选中，恢复普通输入模式
```

## 八、边界情况处理

### 8.1 产能不足

```
场景：订单太多，产能不足以满足所有交期

处理：
1. AI尽可能排产，按交期+优先级排序
2. 无法准时的货柜标红
3. 对话区明确告知：

"以下 3 个货柜预计延期：
 • SEC515920 (DE#) - 延期 2 天
 • SEC515921 (US#) - 延期 1 天
 • SEC515922 (JP#) - 延期 3 天

 建议：
 1. 联系客户协商交期
 2. 考虑部分订单外协
 3. 安排加班生产"
```

### 8.2 库存约束冲突

```
场景：贴标需要的半成品库存不足

处理：
1. 贴标任务自动等待成型产出
2. 甘特图显示"等料"状态
3. 如等待时间过长影响交期，AI提示：

"LABEL-1 需等待 ROTARY-1 产出 8 小时后才能开始。
 建议：调整成型顺序，优先生产该SKU。"
```

### 8.3 ERP数据滞后

```
场景：ERP数据比实际晚1-2天

处理：
1. 每次排产前要求用户确认成型机状态
2. 状态卡片预填系统推算值
3. 用户可修正实际情况
4. 确认后才生成排产
```

### 8.4 用户取消选中

```
场景：用户选中任务后，点击Canvas空白处或按ESC

处理：
1. 取消选中状态（蓝框消失）
2. 输入框上方的上下文卡片消失
3. 用户输入变为通用指令（非针对特定任务）
```

## 九、附录

### 9.1 术语表

| 术语 | 含义 |
|------|------|
| 成型机 / ROTARY | 塑料容器成型的核心设备 |
| 贴标机 / LABEL | 在容器上贴标签的设备 |
| 货柜 / poreference | 一批订单的集合，对应一个出货柜 |
| 换模 | 更换模具，需72小时（仅L1） |
| 换色 | 更换颜色，需12小时 |
| 库存 / Buffer Stock | 非订单驱动的提前备货，利用换模间隙多生产 |
| 准时率 | 能按交期完成的货柜比例 |
| 延迟天数 | 所有延期货柜的延期天数总和 |
| 换产次数 | 成型机换色/换模的次数 |

### 9.2 KPI计算规则

**货柜准时率**
```
准时货柜数 / 总货柜数 × 100%

货柜准时 = 该货柜所有订单的最晚完成时间 ≤ 该货柜最早交期
```

**总延迟天数**
```
Σ max(0, 货柜完成时间 - 货柜交期) for all 货柜
```

**换产次数**
```
成型机上相邻任务SKU不同的次数
（仅计算需要换色/换模的情况）
```
